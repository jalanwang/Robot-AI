# Lecture 09: 왜 힙 메모리를 사용해야 하는가? (Why Use Heap?)

강의의 마지막 섹션으로, 복잡한 현대 프로그래밍에서 힙 메모리가 필수적인 3가지 이유를 정리합니다.

---

### 1. 데이터의 수명(Lifetime) 관리
- **문제**: 스택에 생성된 변수는 함수가 끝나면 자동으로 소멸됩니다.
- **해결**: 함수가 종료된 후에도 데이터를 유지하고, 다른 함수나 객체에게 전달하고 싶을 때 힙 메모리를 사용합니다. 
- **예시**: 팩토리 패턴에서 생성된 객체를 반환할 때.

### 2. 실행 중에 결정되는 크기(Dynamic Size)
- **문제**: 스택 배열은 컴파일 타임에 크기가 결정되어야 합니다. (일부 컴파일러의 VLA 제외)
- **해결**: 사용자 입력, 파일 크기, 네트워크 패킷 등에 따라 메모리 크기를 유동적으로 조절해야 할 때 힙을 사용합니다.
- **예시**: `std::vector`의 내부 동작.

### 3. 대용량 데이터 처리(Large Data)
- **문제**: 스택은 공간이 매우 제한적(보통 1MB~8MB)입니다.
- **해결**: 이미지 처리, 머신러닝 모델, 고해상도 그래픽 등 수십 MB 이상의 데이터를 저장하려면 광활한 힙 영역을 써야 합니다.
- **예시**: 4K 이미지 버퍼 할당.

---

### 💡 결론: Safe C++로 가는 길
- 힙은 강력하지만 **위험**합니다.
- **Raw Pointer (`new`/`delete`)** 대신 **스마트 포인터 (`std::unique_ptr`, `std::shared_ptr`)**를 사용하세요.
- 자원 관리를 자동화하는 **RAII** 패턴을 익히는 것이 현대 C++ 개발자의 핵심 역량입니다.
